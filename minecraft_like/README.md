# Minecraft-подобная мини-игра

Небольшая voxel-песочница в браузере (Three.js):

- Ходьба: `WASD`
- Прыжок: `Space`
- Спуск вниз: `Shift`
- Ломать блок: ЛКМ
- Ставить блок: ПКМ
- Выбор блока: `1` (земля), `2` (стекло), `3` (вода)

Реализовано:

- Блоки с установкой/разрушением.
- Прозрачность стекла.
- Простая физика воды: вода течёт вниз, затем растекается в стороны.
- Базовая физика игрока: гравитация, коллизии, прыжок.

## Запуск на локальном сервере (Node.js)

```bash
cd minecraft_like
npm start
```

После запуска откройте `http://localhost:8080`.

## Альтернативный запуск (Python)

```bash
cd minecraft_like
python3 -m http.server 8080
```

После запуска откройте `http://localhost:8080`.
