# Практическая работа №5 (Python, asyncio)

Простая версия на Python (без лишней сложности):

- `server.py` — асинхронный TCP сервер.
- `client.py` — клиент с 2 режимами:
  1. администратор (добавляет блюда в JSON-меню),
  2. голодный клиент (получает меню, заказывает, платит).

## Что сделано по шагам задания

1. Клиент отправляет запрос на ожидание меню (`WaitMenu`).
2. Сервер отправляет меню (`Menu`).
3. Клиент выбирает блюда (`Order`).
4. Сервер считает чек: количество и итоговую сумму (`Receipt`).
5. Клиент отправляет сумму оплаты (`Payment`).
6. Если сумма меньше чека, сервер отвечает: **«Пойдешь мыть посуду!!!»**.

## Как запустить

Открой 2–3 терминала в папке проекта.

### 1) Сервер

```bash
python3 lab5-async-python/server.py
```

### 2) Администратор

```bash
python3 lab5-async-python/client.py
```

Выбери `1` и добавь блюдо: `id`, `name`, `price`.

### 3) Голодный клиент

```bash
python3 lab5-async-python/client.py
```

Выбери `2`, затем введи ID блюд и оплату.

## Формат файла меню (`menu.json`)

```json
[
  { "id": 1, "name": "Бургер", "price": 220 },
  { "id": 2, "name": "Картофель фри", "price": 120 },
  { "id": 3, "name": "Кола", "price": 90 }
]
```
