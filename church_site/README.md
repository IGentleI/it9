# Сайт храма (Flask)

## Запуск

```bash
cd church_site
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

После запуска откройте `http://127.0.0.1:5000`.

## Фон

Файл фоновой фотографии должен находиться по пути:

`church_site/static/images/temple-bg.jpg`

Если у вас есть исходная фотография храма, сохраните её с этим именем — сайт автоматически подхватит изображение.
