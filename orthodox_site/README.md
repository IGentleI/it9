# Сайт храма (Flask)

## Запуск

```bash
cd orthodox_site
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```

Откройте в браузере: http://127.0.0.1:5000

## Фон

Поместите прикреплённую фотографию храма в файл:

`orthodox_site/static/church-bg.jpg`

После этого фото будет использоваться как фоновое изображение сайта.
