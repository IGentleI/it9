# Сайт храма (Flask)

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте: `http://127.0.0.1:5000`

## Фоновое изображение

Положите фотографию храма в файл:

`static/church.jpg`

В проекте CSS уже настроен на использование этого изображения как фона страницы.
