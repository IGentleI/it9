# Практическая работа №5 (асинхронное клиент-серверное приложение)

Простой вариант для 2 курса:

- `FoodServer` — TCP сервер с бизнес-логикой.
- `FoodClient` — один клиент в двух режимах:
  - **администратор** (добавляет блюдо в меню JSON),
  - **голодный клиент** (получает меню, делает заказ, оплачивает).

## Что реализовано по заданию

1. Клиент запрашивает меню (`WaitMenu`).
2. Сервер отправляет список блюд (`Menu`).
3. Клиент выбирает блюда (`Order`).
4. Сервер считает количество и сумму, отправляет чек (`Receipt`).
5. Клиент отправляет оплату (`Payment`).
6. Если оплата меньше суммы чека — сообщение: **«Пойдешь мыть посуду!!!»**.

## Как запустить

Открой 2–3 терминала.

### 1) Запуск сервера

```bash
dotnet run --project lab5-async/FoodServer/FoodServer.csproj
```

### 2) Запуск клиента-администратора

```bash
dotnet run --project lab5-async/FoodClient/FoodClient.csproj
```

В консоли выбери `1` и добавь блюдо (ID, название, цена).

### 3) Запуск клиента-покупателя

```bash
dotnet run --project lab5-async/FoodClient/FoodClient.csproj
```

В консоли выбери `2`, получи меню, введи ID блюд, затем оплату.

## Формат меню (JSON)

Файл создается автоматически сервером (`menu.json`) и имеет вид:

```json
[
  { "Id": 1, "Name": "Бургер", "Price": 220 },
  { "Id": 2, "Name": "Картофель фри", "Price": 120 },
  { "Id": 3, "Name": "Кола", "Price": 90 }
]
```

Поля соответствуют заданию:
1. Порядковый номер (`Id`)
2. Название блюда (`Name`)
3. Стоимость блюда (`Price`)
